# SYNTHETIC DEMONSTRATION DATA — NOT OFFICIAL INSTITUTIONAL DATA

These files are generated by `generate_synthetic.py` (fixed seed) for software demonstration only.
They are **not** official statistics from BNR, NISR, RURA, the World Bank, any bank or any mobile operator.

| File | Content |
|---|---|
| digital_financial_activity_synthetic.csv | Monthly mobile money / digital payments / mobile banking activity by province, 2020-01 to 2024-12 (transaction_value in RWF million) |
| connectivity_inclusion_synthetic.csv | Monthly connectivity and financial-inclusion indicators in long format, 2020-01 to 2024-12 |
| upload_demo_2025_extension.csv / .xlsx | Jan–Jun 2025 continuation of the first file, used for the live upload demo |
| ground_truth_synthetic_anomalies.json | Injected anomalies, used only by automated tests |
